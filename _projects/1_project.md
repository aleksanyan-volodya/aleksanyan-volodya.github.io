An interactive web platform designed to demystify the Transformer architecture by making its core mechanisms visible and explorable.

**What it does**
- Visualises the attention mechanism step-by-step as input is processed
- Includes an emotion recognition module that runs inference on free-text entered by the user
- Supports online training: the model adapts in the browser as the user provides labelled examples

**Motivation**
Transformers are now the backbone of modern NLP and computer vision, yet their internal workings remain opaque to many. This project was built to bridge that gap through direct interaction rather than static explanation.

**Stack:** Python · PyTorch · Transformers
