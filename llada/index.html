Mini-LLaDA demo

A 33M-parameter masked diffusion language model, running in your browser.

LLaDA generates text by unmasking, not left to right. Generation starts from a fully masked sequence (░░). At each step the model predicts every masked token at once and keeps the most confident ones (highlighted in yellow). The model has 33M parameters and was trained from scratch on TinyStories, so it writes short children’s stories. It runs on your device: the first click downloads it (33 MB). Code on GitHub.
